# AI Assets

A collection of AI-generated images, icons, and videos for your games.

![Filip Monti](Filip-Monti.webp)

## Installation

To install this module in Foundry VTT, paste the following URL into the **Manifest URL** field in the Add-On Modules menu:

```text
https://raw.githubusercontent.com/brunocalado/ai-assets/main/module.json
```

## Usage

Once the module is installed, you can access the included assets anywhere in Foundry VTT that allows file selection (e.g., character sheets, items, macros, journals, or the canvas). 

To use an asset, open the Foundry VTT file picker and navigate to the module's directory. All files are located inside the `modules/ai-assets/` folder.

**Example Path:**
If you want to use the mystery box common icon, the path would be:
```text
modules/ai-assets/fvtt/dh-mystery-box/icons/box-common.webp
```
